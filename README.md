# Spotify 음악 데이터 BI 시각화 포트폴리오

Kaggle **Spotify Tracks Dataset**(114,000행 · 114개 장르)을 Python EDA로 검증하고 Tableau 대시보드로 시각화한 프로젝트입니다.

- 🔗 포트폴리오 페이지: https://perspicacia.github.io/spotify-bi-portfolio/
- 도구: Python(pandas), Tableau
- 핵심: KPI 정의(AVG · COUNTD), KPI → 순위 → 관계 3단 대시보드 설계, 집계 수준에 따른 해석 차이

## English

A BI project that checks the Kaggle **Spotify Tracks Dataset** (114,000 rows · 114 genres) with Python EDA and visualizes it in a Tableau dashboard.

- 🔗 Portfolio page (English): https://perspicacia.github.io/spotify-bi-portfolio/en/
- Tools: Python (pandas), Tableau
- Highlights: KPI definitions (AVG · COUNTD), a three-layer dashboard (KPI → ranking → relationship), and how the aggregation level changes interpretation
